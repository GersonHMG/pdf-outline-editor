PDF Outline Editor

View and edit a PDF's bookmarks as JSON. Everything runs in your browser — the file is never uploaded.

Outline

Load a PDF to see its outline.

JSON

JSON format

An array of entries. Each entry has:

  • title (string, required)
  • page (1-based page number) or url (external link)
  • children (array of entries, optional)
  • open (boolean, optional — expand this entry by default)

An empty array [] removes the outline.

Built with PDF.js and pdf-lib.
